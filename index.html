Sentient Cannon

If you can read this, the game isn't running.
Your phone opened the file in a preview window that can't run games. Open it in Safari or Chrome instead.

iPhone / iPad

  1. The Mail, Gmail and Files previews can't run games, and Safari can't open game files saved on the phone.
  2. Ask Dominik for the web link to the game and tap it. It opens in Safari and plays right away.
  3. Or play it on a computer: save the file and double-click it.

Android

  1. Tap the download arrow on the attachment to save it.
  2. Open the Files app, go to Downloads, press and hold sentient-cannon.html, then choose Open with → Chrome.
  3. If Chrome isn't offered, open Chrome and type file:///sdcard/Download/sentient-cannon.html in the address bar.

Computer

Save the file and double-click it. It opens in your web browser. Aim with the mouse and hold the left button to fire.
